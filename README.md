# medschool-ai-journal · 医学生 AI 学习实录

医学生的 AI / 编程课程作业合集。按课程分目录整理，记录从零开始的完整学习轨迹，也适合医学背景的同学参考入门。

## 目录

| 目录 | 课程 | 内容 |
|---|---|---|
| `machine-learning/` | 机器学习 | PCA/SVD 降维、随机森林、k 近邻、集成学习、特征工程、数据可视化 |
| `computer-vision/` | 计算机视觉 | OpenCV/PIL 图像处理、几何变换、角点检测、缩略图与裁剪 |
| `nlp/` | 自然语言处理 | 中文分词、BERT、文本分类、词云、特征工程 |
| `medical-imaging/` | 医学图像处理 | MATLAB：几何变换、直方图均衡、去噪锐化、边缘检测、图像配准 |
| `bioinformatics/` | 生物信息学 | 生信分析脚本与 Jupyter 建模笔记 |
| `big-data/` | 大数据与精准医学 | 课程练习（Q11–Q22） |
| `python-exercises/` | Python 练习 | 计算机等级考试（Python）练习题 |
| `blockchain/` | 区块链 | 钱包、网络、GUI 演示作业 |
