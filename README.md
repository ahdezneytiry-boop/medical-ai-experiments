# medical-ai-experiments · 医学场景 AI 实验集

围绕医学场景的 AI 实验代码集合，覆盖机器学习、计算机视觉、自然语言处理、医学图像处理、生物信息学与大数据分析。

## 目录

| 目录 | 方向 | 内容 |
|---|---|---|
| `machine-learning/` | 机器学习 | PCA/SVD 降维、随机森林、k 近邻、集成学习、特征工程 |
| `computer-vision/` | 计算机视觉 | OpenCV/PIL 图像处理、几何变换、角点检测 |
| `nlp/` | 自然语言处理 | 中文分词、BERT、文本分类、词云 |
| `medical-imaging/` | 医学图像处理 | MATLAB：几何变换、直方图均衡、去噪锐化、图像配准 |
| `bioinformatics/` | 生物信息学 | 生信分析脚本与 Jupyter 建模笔记 |
| `big-data/` | 大数据分析 | 数据查询与特征练习 |
| `python-snippets/` | Python | 常用代码片段 |
| `blockchain/` | 区块链 | 钱包、网络、GUI 演示实现 |

## 说明

- 报告文档（含个人信息）未包含在本仓库。
- 部分脚本为早期练习代码，质量参差，仅供学习交流。
